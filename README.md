# 📚 LEP - Sistema de Reservas

Sistema de gerenciamento de reservas do **Laboratório de Engenharia de Produção (LEP)** da **Universidade Federal do Pará (UFPA)**.

![License](https://img.shields.io/badge/license-MIT-green?style=flat-square)

---

# ✨ Funcionalidades

## 👤 Usuários

* 📅 Reserva de horários do laboratório
* 🌅 Turnos manhã, tarde e noite
* 🔍 Consulta rápida de reservas
* 📱 Campo WhatsApp formatado automaticamente
* 📋 Visualização das regras do LEP

## 🔐 Administradores

* 📊 Dashboard com estatísticas
* ✅ Aprovação manual de reservas noturnas
* 📎 Exportação em Excel, CSV, PDF e JSON
* 🔄 Gerenciamento completo das reservas
* 🔐 Login seguro com Firebase

# 🚀 Como Executar

## Clone o projeto

```bash id="21ug7n"
git clone https://github.com/seu-usuario/lep-reservas.git
cd lep-reservas
```

## Execute

Abra o arquivo `index.html` no navegador
ou utilize o **Live Server** no VS Code.
